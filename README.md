# منصة دينا — الخطة الأسبوعية والنصاب والجدول الدراسي

منصة موحّدة لمدارس دينا العالمية (تسجيل دخول + قاعدة بيانات Supabase):

- **الخطة الأسبوعية**: بوابة المعلم، لوحة المتابعة، مراجعة واعتماد، تصدير PDF بهوية دينا.
- **الجدول الدراسي**: مسودات واعتماد، استيراد Excel، إسناد المعلمين، وربط مع الجدول الآلي.
- **احتساب النصاب** و**الجدول الآلي** (`tools/`): تظهر لمن يملك صلاحيتها فقط.

الملفات ثابتة وتُنشر على GitHub Pages. الحماية الفعلية للبيانات في قاعدة البيانات عبر صلاحيات الصفوف (RLS).
وضع التجربة: `index.html?demo=1`.
