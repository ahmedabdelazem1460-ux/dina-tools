# اختبارات المنصة (Playwright)

```bash
python3 -m http.server 8766 &          # من جذر المشروع
cd tests && mkdir -p p0 && node t70.js  # الانحدار العام (كل الصفحات، ثلاثة مقاسات)
```
| الملف | يغطي |
|---|---|
| `t70.js` | انحدار عام: فتح الصفحات الرئيسية بلا أخطاء وبلا تمرير أفقي |
| `t165.js` | تبويب الطلاب والقوائم التفاعلية |
| `t166–t169.js` | التوقيت: الفحص، الجدول المعتمد، الصلاة بعد آخر حصة، الفئات، الحفظ |
| `t170.js` | استيراد الأسئلة (Excel/Word/PDF/صورة)، البنك، إنشاء واجب، بنك المدرسة، الإتاحة |
| `t171.js` | مخرجات القراءة الضوئية لصورة (`node t171.js fx/q.png`) |
| `t172.js` | واجهات الطالب الخمس على الجوال والحاسب |
| `t185.js` | البوصلة ٢ (البنك، المعاينة، تقارير الفصل والطالب بالإنجليزية)، رعاية الموهوبين (ترشيح، تقدير، إبداع، قرار اللجنة، المؤشرات)، السمات، الإشعارات، لوحة المعلم، scale.html بثلاث لغات ومستوى الروضة — `node t185.js [عرض]` |
| `t186.js` | البوصلة: رابط الطلاب الخارجيين، المشاركة مع المعلمين، التصدير الإبداعي (تنزيلات فعلية)، المعلم بلا تفعيل (لا جديد إلا السمات) — `node t186.js [عرض]` |
| `t188.js` | بطاقة الميزات الجديدة: الحفظ والتغذية الراجعة، البحث والتصفية، الإسناد لمعلمين محددين، بند الاختبارات والواجبات الإلكترونية |
| `t189.js` | صفحة المعلم: جرس الإشعارات وتطبيق الجوال في لوحة المعلم والرئيسية، المجموعات، ترتيب المواد والصفوف |
| `t190.js` / `t190ui.js` | القراءة الذكية لصور الأسئلة (جداول + الإجابة المظللة) ونافذة الاستيراد — `node t190.js صورة.png` (`fx/mkhl.js` يولّد `fx/hl.png`) |
| `t191.js` | أدوات السبورة التفاعلية (فصل الحصة، العجلة، البطاقة، النجوم، الأدوار، المجموعات، الضجيج…) بثلاثة مقاسات، والسؤال اللحظي، وإخفاؤها عن المعلم بلا تفعيل |
| `t192.js` | بنك الأسئلة: التعديل لواضع السؤال وللمالك فقط، وضع التحرير، التحرير السريع، النسخ، التعديل الجماعي |
| `t193.js` | كراسة التدريب PDF: الأنماط الثلاثة، التقسيم بلا فيض، QR، تنزيل PDF فعلي، إطار الطباعة |
| `t194.js` | التنبيهات الآلية: إشعار لا رسالة، و«كرسالة أيضاً»، والرسالة لمن لم تُفعَّل له الإشعارات |
| `t173.js` | تطابق الحزمة `index.html` مع المصادر `index.dev.html` |

كلها تعمل على وضع التجربة `?demo=1` ولا تمس قاعدة البيانات. اللقطات في `tests/p0/` (غير مودعة).
